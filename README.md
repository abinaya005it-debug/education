# EduBot - Gemini 3.1 Flash-Lite

Education-domain AI chatbot built with Flask and the Google Gen AI SDK.

## Setup

1. Open `.env`.
2. Replace `PASTE_YOUR_NEW_API_KEY_HERE` with your own Gemini API key.
3. Install packages:

   pip install -r requirements.txt

4. Run:

   python app.py

5. Open:

   http://127.0.0.1:5000

The model is set to `gemini-3.1-flash-lite`.
